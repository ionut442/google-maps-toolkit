# Google Maps Toolbox design direction

The detailed visual reference remains in `airbnb.design.md`. This product-specific layer translates it into the private-beta interface implemented in the application.

- Use a white canvas with soft neutral section surfaces and subtle borders.
- Keep one restrained blue accent for primary actions, focus, and active states.
- Prefer modest headings, short explanatory copy, and compact progressive disclosure.
- Use rounded cards, 48 px interactive targets, and consistent inline icons for tools.
- Group onboarding fields by task and show customer-facing previews beside configuration.
- On mobile, keep forms single-purpose, prevent horizontal overflow, and surface the current primary action without obscuring content.
- Never imply geographic boundaries that the source data does not provide; map pins represent confirmed place centres only.
- Keep credential evidence visibly associated with its credential while preserving owner-only access.
